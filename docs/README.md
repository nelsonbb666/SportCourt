# Documentación — SportCourt

Carpetas recomendadas conforme crezca el proyecto:

- `arquitectura/` → diagramas y decisiones técnicas (ADR)
- `api/` → especificación y ejemplos de endpoints
- `producto/` → requisitos, user stories, alcance

Sugerencia: registra cada decisión importante como un ADR
(`docs/arquitectura/ADR-001-stack.md`, por ejemplo).
